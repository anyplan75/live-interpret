    내용과 이름

    휴대폰 대수

    0이면 휴대폰 없이 시작합니다. 연결 번호와 QR은 방송실에 나옵니다.

    계정 사용

    계정마다 남은 잔액, 남은 시간, 최근 사용을 보고 선불 잔액을 더합니다.
